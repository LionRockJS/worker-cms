# ISO/IEC 27034 implementation matrix for 0xCMS

**Assessment date** 2026-11-04 · **Repository revision** `e882916` · **Result** Partial alignment with the application security management process. The CMS implements and tests several security controls. The reviewed code does not establish which controls an owner selected for a release, what level of trust they were meant to achieve, or whether that level was achieved.

## Scope and interpretation

This review maps the CMS host to the concepts in [ISO/IEC 27034-1](https://www.iso.org/standard/44378.html), the organizational framework in [Part 2](https://www.iso.org/standard/55582.html), and the five application management activities in [Part 3, §§6.1–6.5](https://www.iso.org/obp/ui/#iso:std:iso-iec:27034:-3:ed-1:v1:en). These references define the assessment criteria. All implementation findings below come from repository code, tests, executable checks, or configuration. No files in the docs folder were used. Scope is the host at this revision and selected control paths. The assessment uses the public ISO descriptions and does not provide a clause-by-clause conformity opinion for the entire series.

**Implemented** means the cited executable path performs the stated activity within its listed scope. **Partial** means the code supports part of the outcome and the row identifies what remains unestablished. **Not evidenced** means the review found no source basis for the outcome. Organizational approvals, branch protection, production settings, and operating records may exist elsewhere. Test execution is identified separately.

Each row below corresponds to an open assessment row above. The roles are proposed decision makers. A named person must accept each assignment. The acceptance tests describe future work.
